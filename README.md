> **Building Solid Foundations for Tomorrow's Leaders.**

Dagrojel Excel Academy is a premium educational institution website designed to provide a comprehensive digital presence for a multi-level school (Reception, Nursery, Primary, and Secondary). This project features a modern, high-performance web interface built with the latest web technologies.

---

## ✨ Features

- **🚀 Highly Responsive**: Optimized for all devices, from mobile phones to high-resolution desktops.
- **🎓 Academic Hub**: Dedicated sections for Reception, Nursery, Primary, and Secondary programs.
- **📰 News & Events**: Stay updated with the latest happenings at DEA through an integrated news system.
- **📸 Interactive Gallery**: High-quality visual showcase of school facilities and student activities.
- **📝 Admissions Portal**: Easy-to-navigate admissions information and application pathways.
- **📧 Contact System**: Professional contact forms and location mapping (Abuja, Nigeria).
- **🎨 Premium Design System**: Custom-tailored typography (Playfair Display & Inter) and a sophisticated color palette (Maroon, Royal Blue, and Gold).
- **⚡ Performance First**: Built with Vite and SWC for lightning-fast development and production builds.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0 or higher)
- [npm](https://www.npmjs.com/) or [Bun](https://bun.sh/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ocholijoseph/dagrojel.git
   cd dagrojel
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🧪 Testing

The project uses **Vitest** for testing. To run the test suite:

```bash
# Run tests once
npm run test

# Run tests in watch mode
npm run test:watch
```
